# Chính sách quyền riêng tư — Sổ Thu Chi

Repo này **chỉ** để host công khai trang chính sách quyền riêng tư của ứng dụng
Android **Sổ Thu Chi** (`com.quyetnm.sothuchi`) qua GitHub Pages, vì repo mã nguồn
của app là private (GitHub Pages cho repo private cần gói trả phí).

- Trang chính: [`privacy-policy.html`](privacy-policy.html)
- `index.html` chỉ là trang chuyển hướng sang file trên.

## Khi sửa nội dung
File gốc là `docs/privacy-policy.html` trong repo mã nguồn. Sửa ở đó trước, rồi
copy sang đây, commit + push. GitHub Pages tự cập nhật sau ~1 phút.
Nhớ đổi ngày "Hiệu lực từ" ở đầu trang khi có thay đổi có ý nghĩa.
